## antislop
For UI, copy, people, mobile layout, or code comments work, read `DESIGN.md` (direction) and adhere to anti-slop guidelines:
- UI / visual: Purpose-tested layout, no generic glows, no floating shadows, no template cards.
- Copy & text: Specific, human language. Zero em dashes (`—`), zero AI marketing buzzwords.
- People & Accessibility: WCAG AA contrast (≥ 4.5:1), keyboard navigation (Tab/Enter/Space/Escape), visible focus indicators.
- Mobile / responsive: 44px minimum tap targets, zero horizontal overflow.
- Code comments: Concise, purpose-driven, zero AI boilerplate.
